# gas_sample
GAS(Google App Script)のサンプルコードです。

Googleスプレッドシートのセルやシートの操作やGoogleカレンダーへ予定の追加の方法を記述しています。

拡張機能→Apps Scriptを選択してエディタを開き、コードを記述してください。

![スクリーンショット](./Screenshot%202026-01-31%2012.01.22.png)

貼り付けたコードを初めて実行するには、Googleアカウントでの認証が必要です。

Googleで「GAS　認証　実行」などのキーワードで検索すると解説しているページが表示されます。

[こちらのページ](https://auto-worker.com/blog/?p=609)

がわかりやすいかもしれません。

また、上記にあわせてGoogleフォームの知識が必要です。検索するといろいろと解説しているサイトが出てきます。参考にしてみてください。
